# 🎵 音乐获取工具

一个纯 Python 标准库实现的命令行音乐获取工具，支持多个音乐平台，可获取 VIP 歌曲播放链接，无需安装任何第三方依赖。（欢迎PR）

## ✨ 功能特点

- 🎧 支持三个平台：网易云音乐、咪咕音乐、波点音乐  
- 🔍 可自定义搜索数量（默认 10 首），避免翻唱版本干扰  
- 📋 显示多个搜索结果供用户选择  
- 🔄 网络请求自动重试（次数、延迟、超时均可配置）  
- 📜 历史缓存：成功获取的歌曲自动保存，可随时查看最近记录  
- ⚙️ 设置界面：交互式修改配置（搜索数量、超时、重试、彩色输出等）  
- 🎨 彩色输出（可关闭）  
- 🚫 零第三方依赖 —— 仅使用 `urllib`、`json` 等标准库  

## 📁 生成的文件

| 文件 | 说明 |
|------|------|
| `setting.json` | 用户配置文件，首次运行自动生成 |
| `cache.json`   | 历史缓存文件，存储成功获取的歌曲信息 |

## ⚙️ 可配置项

通过主菜单进入 **⚙️ 设置脚本** 可调整：

- 默认搜索数量（1~任意整数）  
- 请求超时秒数  
- 最大重试次数及重试间隔  
- 最大缓存条目数  
- 彩色输出开关  
- DEBUG 模式开关（打印 API 原始返回数据）  

## 📜 历史记录

成功获取的音乐会自动保存到缓存，包含：
- 获取时间
- 歌曲名、歌手
- 播放链接
- 来源平台

可在主菜单选择“查看历史记录”浏览最近 10 条。

## ⚠️ 注意事项

- 本工具仅供学习交流，获取的音乐链接有时效性，请勿用于商业用途。

## ❓ 常见问题（FAQ）

**Q：为什么搜索结果里没有我想要的版本？**  
A：可以尝试增加“搜索数量”（默认10），获取更多结果；或者更换平台（网易云、咪咕等），不同平台的曲库有差异。

**Q：获取到的链接打不开或很快失效怎么办？**  
A：音乐链接有时效性，请尽快使用。如果失效，重新运行脚本搜索同一首歌即可获取新链接。

**Q：网络总是超时或重试失败？**  
A：进入“设置脚本”，适当增加“请求超时秒数”（如改为15或20）和“最大重试次数”（如5）。如果仍然失败，请检查网络连接。

**Q：彩色输出乱码或不想用颜色？**  
A：在设置中将“彩色输出开关”关闭即可。部分老旧终端可能不支持 ANSI 颜色代码。

**Q：历史缓存太多，如何清空？**  
A：直接删除 `cache.json` 文件即可。或者减小“最大缓存条目数”设置，超出部分会自动丢弃。

**Q：为什么有时候搜索到歌曲但获取播放链接失败？**  
A：可能该歌曲无版权或API限制。可以尝试其他平台或更换搜索关键词（如“歌名 原唱”）。

**Q：能否下载音乐文件到本地？**  
A：本工具只获取播放链接，你可以用浏览器打开链接后另存为，或使用命令行工具下载，例如：（Ubuntu）
    wget "音乐链接" -O 歌名.mp3

**Q：DEBUG模式有什么用？**  
A：开启后会在请求时打印 API 返回的原始 JSON 数据，方便开发者排查问题（例如查看是否返回了歌词、封面等额外信息）。

**Q：配置修改后如何恢复默认？**  
A：删除 `setting.json` 文件，下次运行脚本会自动生成默认配置。
