> 🎵 轻量级命令行音乐搜索工具 — 纯 Python 标准库，零依赖

获取网易云音乐、咪咕音乐、波点音乐等平台的**音乐直链**。

## 特点

- ✅ **零第三方依赖** — 仅使用 `urllib`、`json` 等标准库
- ✅ **零配置文件** — 无需 `setting.json`，开箱即用
- ✅ **多平台支持** — 网易云音乐 / 咪咕音乐 / 波点音乐
- ✅ **DEBUG 模式** — 启动时加 `--debug` 即可查看 API 原始返回

## 使用方法

```bash
python main.py           # 正常模式
python main.py --debug    # DEBUG 模式（打印 API 原始数据）
```

运行后按提示操作：

1. 选择音乐平台（1-3）
2. 输入歌名/关键词
3. 选择搜索数量（默认 10 首）
4. 从结果中选择歌曲
5. 获取播放链接，浏览器打开即可收听

git checkout min-cmd    # 回到精简版

## ⚠️ 注意事项

- 本工具**仅供学习交流**，获取的音乐链接**有时效性**
